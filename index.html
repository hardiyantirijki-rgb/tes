Tentang Proyek Ini

Halaman tunggal atau *Single-Page Application* ini dirancang agar efisien, mudah dimengerti, dan langsung dapat digunakan untuk berbagai keperluan seperti portofolio, landing page, atau profil singkat.

Semua elemen dikemas rapi dalam satu file kode tunggal sehingga sangat praktis untuk diunggah dan dijalankan di server manapun.

  • ✓ Navigasi mulus (Smooth Scrolling)
  • ✓ Interaksi JavaScript ringan
